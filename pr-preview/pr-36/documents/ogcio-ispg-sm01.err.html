<title id="_61998878-2bff-eff7-7263-05a3fe373b29">Introduction</title>
<p id="_39dc277e-4b07-3aa8-a86e-40c55615f06f">Information Technology (IT) security risk assessment and security audit are the major components of information security management. This document provides a reference model to facilitate the alignment on the coverage, methodology, and deliverables of the services to be provided by independent security consultants or auditors. With this model, managerial users, IT managers, system administrators and other technical and operational staff can have more understanding about security risk assessment and audit. They should be able to understand what preparations are required, which areas should be noted, and what results would be obtained. It is not the intention of this document to focus on how to conduct a security risk assessment or audit.</p>

<title id="_cfb89243-7ed8-409a-3942-f7ec2d535dff">Security Audit</title>
<p id="_345840e5-beda-fc1f-9937-eff585fca6c9">Security Audit is an audit on the level of compliance with the security policy or standards as a basis to determine the overall state of the existing protection and to verify whether the existing protection has been performed properly. It targets at finding out whether the current environment is securely protected in accordance with the defined security policy. It should be performed periodically to ensure the compliance of the security policies and effective implementation of security measures.</p>

<p id="_30426180-2211-678f-75a1-9c8c16873e7b">A security audit will require security policy and standards, audit checklists and an inventory list, which may cover different areas such as web application, network architecture, wireless communication, etc. <xref target="annexC"/> lists different audit areas. <xref target="annexD"/> provides a sample checklist where items to be checked under different security areas. Security audit may also involve the use of different auditing tools and different review techniques in order to reveal the security non-compliance and loopholes. After the audit process, an audit report will be prepared to highlight the conformance and gaps existed between the current protection and the requirements specified in the security policies.</p>
